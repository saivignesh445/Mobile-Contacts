# Mobile-Contacts
Contacts Management Notebook
This Jupyter Notebook provides a simple implementation for managing contact information using Python. It allows users to create, store, search, and manipulate contact records. The notebook is ideal for learning basic Python programming concepts such as dictionaries, lists, loops, and user-defined functions.

## Features
=> Add new contacts with name, phone, and email.

=> Display all saved contacts.

=> Search contacts by name.

=> Delete contacts.

=> Update existing contact details.

## Requirements
- Python 3.x
- Jupyter Notebook
- No external libraries are required.

## How to Use
1. Open the notebook using Jupyter.
2. Run each cell in sequence.
3. Follow the input prompts to manage your contacts.
